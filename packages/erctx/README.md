# erctx

Short command for [easy-repo-context](https://www.npmjs.com/package/easy-repo-context). Same tool, same commands:

```
npx erctx plan
npx erctx check
```

Installing `easy-repo-context` (`npm i -g easy-repo-context`) already gives you both `easy-repo-context` and `erctx`. This package only makes `npx erctx` resolve to it.
